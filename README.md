# Binary Beginning 4.2 — Your First GitHub Contribution 🚀

Welcome to the hands-on Git & GitHub challenge!

**Goal:** Submit your first Pull Request (PR) by adding a short Markdown file about yourself.

## Your challenge
1. Sign in to GitHub and **Fork** this repository.
2. Clone your fork to your computer (or use GitHub's web editor).
3. Create a new branch, e.g. `git switch -c add-yourname`.
4. Create `contributors/your-github-username.md` using the example as a guide.
5. Commit and push your branch.
6. Open a Pull Request **from your fork's branch into this repository's `main` branch**.

Read [CONTRIBUTING.md](CONTRIBUTING.md) for the full beginner-friendly walkthrough.

## Contribution format
Include your display name (or nickname), GitHub username, and one technology you want to learn. **Do not include private information** such as phone numbers, email addresses, student IDs, or home addresses.

## Success!
Your challenge is complete when you have **opened a Pull Request**. A maintainer may review it before merging.
